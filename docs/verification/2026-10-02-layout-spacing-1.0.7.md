# 자동·유동 간격 판정 개선 — 1.0.7

## 변경

- 기존 정확한 `auto` 마진 제외를 유지하면서 공백·대소문자 정규화를 보강했다. 작성 선언이 auto임을 확인한 경우에만 제외한다.
- 간격의 `%`, viewport/container 상대 단위, calc/min/max/clamp/env 표현식은 `review`, `reason: fluid-layout`, `value: unknown`으로 분리한다. 계산식이 고정 결과를 만들 수도 있으므로 정상으로 자동 면제하지 않는다.
- UI와 리포트의 판정 라벨은 ‘유동 레이아웃 확인’. 상세에는 적용 선언과 고정 토큰으로 바꾸지 말라는 안내를 제공한다.
- CSS 선언을 찾지 못한 간격은 ‘CSS 선언 확인 필요’. 자동 정렬 가능성을 확인하도록 안내하고 위반 판정·수정값 추천을 보류한다.
- review 상태의 간격에는 고정 FDS 토큰 대체값을 추천하지 않는다.
- 직접 작성된 118.844px는 그대로 불일치 후보다. 소수점이라는 이유로 면제하지 않는다.
- 같은 계산값이라도 작성 선언이 다른 방향의 padding/margin/gap을 하나의 항목으로 합치지 않는다. 리뷰 이유가 다른 목록 그룹도 분리한다.

기존 메시지 문자열의 ‘미등록/원시값’ 형태는 호환성을 위해 유지한다. 사용자 판정은 assessment 메타데이터를 우선 사용한다. 패키지 소속 자동 판별, 접근 불가능한 스타일시트 읽기, 변수의 전체 의존 경로 추적을 구현한 것은 아니다. 사진의 118.844px가 실제 auto였는지는 이 변경만으로 확정하지 않는다.

## 검증

TDD: 새 요구에 대한 실패 확인 후 구현. 자동 마진 정규화, 직접 소수점 간격, %, vw, calc/min/clamp, 혼합 선언, CSS 선언 부재, 유동 목록 라벨, 확인 필요 간격의 수정값 추천 차단을 테스트한다.

`npm test`: 334개 성공, 실패 0개.

Ego 에이전트 전용 fixture에서 브라우저 CSSOM을 실제 읽어 검사했다:

- auto → 최종 300px → issue 없음
- 20% → 최종 100px → 유동 레이아웃 review
- 118.844px 직접 선언 → 최종 118.844px → mismatch 후보

이는 설치된 Chrome 확장앱 전체 E2E 검증이 아니라 실제 브라우저 DOM·CSSOM과 검사 모듈의 통합 검증이다. 사용자 탭을 변경하지 않았고 QA 공간은 종료했다.

빌드 버전 1.0.7. 적용하려면 Chrome 확장앱을 다시 로드하고 대상 페이지를 새로고침하여 재검사한다. 대상 앱·Figma·Git 원격은 변경하지 않았다.
